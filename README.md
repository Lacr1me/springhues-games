# springhues-games

Springhues 的**游戏资源**发布仓库（Mod、整合包、工具、小游戏等）。网站：https://springhues.com/

- 本仓库不提交大文件，只用 **GitHub Releases** 分发；源码如需公开可另放分支或子目录。
- 一个 Release = 一个作品的一个版本，tag 形如 `n1ten-v1.5.2`。
- 附件文件名只用 ASCII：`<名称>-<版本>-<加载器与游戏版本>.<扩展名>`，并附同名 `.sha256` 校验文件。
- 现有作品：N1ten（十重天），Minecraft Java 1.20.1 / Forge。
- 站点源码在 Lacr1me/game-daily，维护与发布流程见该仓库的 `docs/HANDOFF.md`。
